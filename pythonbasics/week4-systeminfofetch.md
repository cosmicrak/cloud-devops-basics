\# Week 4 Day 22 - Python System Info



\## What I built

I built system\_info.py to collect basic machine, user, directory, path, and environment information.



\## Modules used

\- os

\- platform

\- getpass

\- pathlib.Path



\## What os is used for

os helps Python interact with the operating system and environment variables.



\## What platform is used for

platform gives information about the operating system and machine.



\## What pathlib is used for

pathlib helps safely work with file and folder paths.



\## Failure case tested

The script checked missing folders like configs without crashing.



\## Cloud Support use

A system info script helps quickly understand which server/user/environment a script is running inside.
