\# Week 3 Day 18 - Python File I/O



\## What File I/O means

File I/O means reading from files and writing to files.



\## with open()

with open() safely opens a file and closes it automatically after use.



\## Modes

\- r = read

\- w = write/overwrite

\- a = append



\## pathlib

pathlib helps work with file paths safely.



\## Script built

file\_io\_drill.py



\## What the script does

It reads sample.log, prints ERROR lines, counts them, and writes the count to result.txt.



\## Why this matters for Cloud Support

Cloud Support engineers often read logs, check config files, and generate summary reports from system files.
