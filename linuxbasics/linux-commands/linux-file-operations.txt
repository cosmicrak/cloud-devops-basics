# Linux File Operations

## Why this matters
Linux file commands are used in DevOps and cloud work to manage server files, logs, scripts, configs, and deployment folders.

## Commands practiced

### cp
Copies files.

Example:
cp file1.txt copy-file1.txt

### mv
Moves or renames files.

Example:
mv file2.txt renamed-file2.txt

### rm
Deletes files.

Example:
rm temp.txt

### nano
Terminal text editor used to edit files.

Save in nano:
Ctrl + O
Enter
Ctrl + X

### head
Shows the first lines of a file.

### tail
Shows the last lines of a file. Useful for checking logs.

### grep
Searches text inside files.

Example:
grep "Linux" notes.txt

### find
Finds files by name or pattern.

Example:
find . -name "*.txt"
