\# Day 01 - Linux Filesystem and Core Commands



\## What I learned

Today I learned how Linux folders are organized and practiced basic file commands.



\## Important Linux folders



| Folder | Meaning |

|---|---|

| / | root folder |

| /home | user files |

| /etc | configuration files |

| /var | changing data |

| /var/log | logs |

| /usr | installed programs |

| /bin | essential commands |

| /tmp | temporary files |



\## Commands practiced



\### pwd

Shows current directory.



\### ls and ls -la

Lists files. ls -la shows hidden files and details.



\### cd

Moves between folders.



\### mkdir

Creates folders.



\### touch

Creates empty files.



\### cat

Shows file content.



\### cp

Copies files.



\### mv

Moves or renames files.



\### rm

Deletes files.



\### rmdir

Deletes empty folders.



\### which

Shows where a command is located.



\## Lab I performed

I created a folder structure with notes, scripts, logs, and backup folders. I created files, wrote text, copied logs, renamed files, and deleted temporary files.



\## Why this matters for Cloud Support

Cloud support engineers need to know where configuration files and logs are stored. Many troubleshooting tasks start by checking the current directory, reading config files, and inspecting logs.
