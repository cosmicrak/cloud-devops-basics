# Week 3 Day 15 Python Automation Mindset

## Manual way
A support engineer manually checks servers one by one.

## Automation way
A script stores server data, loops through it, checks status, and prints alerts.

## Why this matters
Automation reduces repeated manual work and makes checks consistent.

## Example use cases
- find stopped servers
- count running servers
- remove duplicate IPs
- generate health reports
- parse logs
