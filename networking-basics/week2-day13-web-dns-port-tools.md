\# Week 2 Day 13 - Web, DNS and Port Tools



\## curl

curl sends web requests from terminal.



Commands practiced:

\- curl -I https://google.com

\- curl -v https://google.com

\- curl -I http://localhost

\- curl http://localhost



\## wget

wget downloads files or web pages.



Command practiced:

wget -O test.html http://localhost



\## nslookup

nslookup checks DNS resolution.



Commands practiced:

\- nslookup google.com

\- nslookup fakehost123456789.com



\## nmap

nmap scans hosts for open ports.



Commands practiced:

\- nmap localhost

\- sudo systemctl stop nginx

\- sudo systemctl start nginx



\## What I understood

curl checks web responses, nslookup checks DNS, wget downloads content, and nmap shows open ports.



\## Cloud Support use

If a website is failing, I can check DNS with nslookup, HTTP response with curl, and open ports with nmap.
