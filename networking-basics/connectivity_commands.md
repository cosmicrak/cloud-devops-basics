\# Week 2 Day 11 - Connectivity Commands



\## ping

ping checks whether a host is reachable.



\## Latency

Latency is the response time, usually shown in ms.



\## Packet loss

Packet loss means some packets did not return.



\## ip addr

ip addr shows network interfaces and IP addresses.



\## traceroute

traceroute shows the network path/hops to a destination.



\## Commands practiced

\- ping google.com -c 4

\- ping 8.8.8.8 -c 4

\- ip addr

\- hostname -I

\- traceroute google.com



\## Diagnosis rule

If ping to IP works but domain fails, DNS may be the issue.

If ping to both IP and domain fails, connectivity may be the issue.
