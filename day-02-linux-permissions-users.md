\# Day 02 - Linux Permissions and Users



\## What are Linux permissions?



\## Meaning of r, w, x



\## Permission numbers

\- 4 = read

\- 2 = write

\- 1 = execute



\## chmod 755

User can do x , r ,w but groups and others can r , x



\## chmod 644

User can do w , r and other can only r



\## chmod 600

User can do w , r and other can not do nothing



\## chown

user grants and accesses the permission to groups 



\## /etc/passwd

&#x20;it stores essential local user account information



\## /etc/shadow

It stores the passwords which were shown as 'x' in /etc/passwd in hash table form
